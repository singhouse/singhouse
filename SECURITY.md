# Security policy

## Reporting a vulnerability

Please report security problems privately. Do not open a public issue.

- Preferred: use **Report a vulnerability** on this repository's
  [Security tab](https://github.com/singhouse/singhouse/security/advisories/new).
- Or email **admin@sing.house**.

Include what you found, how to reproduce it, and which version or commit you
tested. We will acknowledge your report, keep you updated while we work on a
fix, and credit you in the advisory unless you prefer otherwise.

## Supported versions

Singhouse is in pre-release. Fixes go into the newest release only.
