# Contributing to Singhouse

## Proposing changes

Please [open a discussion](https://github.com/singhouse/singhouse/discussions)
before starting work or submitting a pull request. Wait for a maintainer to
agree on the scope; we'll send you the contribution requirements privately
before work begins.

## Pull requests

- Link to the agreed discussion and explain what changed and why.
- Keep each PR focused and follow the surrounding code style.
- Add or update tests for behavior changes and describe what you tested.
- Preserve license notices and identify the source of any third-party material.

See the [backend](backend/README.md) and [frontend](frontend/README.md)
guides for development setup, and [AGENTS.md](AGENTS.md) for the code layout
and test commands.

## Reporting bugs

[Open an issue](https://github.com/singhouse/singhouse/issues) with your app
version, operating system, steps to reproduce, and what you expected versus
what happened. For audio processing problems, include your GPU details and
relevant logs. Remove personal information before posting.

Report security issues privately using [SECURITY.md](SECURITY.md).
